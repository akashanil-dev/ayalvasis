# Icon credits

Each desktop environment uses its own icon theme, as real Linux desktops do. Files are named after the
TuxOS app that uses them. Icons from other projects are used unmodified under their licenses.

## CDE: `cde/`

Drawn for TuxOS in the style of the 1990s Motif desktop: a CRT terminal, a filing cabinet, a notepad,
falling blocks, the Style Manager palette and a floppy disk.

Apps without a file here (Learn Linux, About) use TuxOS's own icons in every desktop.
